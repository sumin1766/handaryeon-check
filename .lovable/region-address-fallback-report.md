# 병합 교회 주소 보정 및 목록 요약 문구 변경

## 원인
- 목록과 지도/표는 이미 `confirmedRegionUnits`를 함께 호출하고 있었다. 별도 목록 분류 코드가 원인은 아니었다.
- 공통 함수에서 대표 확정 건이 존재하면 주소가 비어 있어도 해당 건을 선택해 다른 확정 건의 유효 주소로 넘어가지 않았다. 현재 소스 기준 지도/표에도 같은 잠재 오류가 있었다.
- 실제 활성 시즌 `테스트` 교회 SELECT 확인: 대표 확정 건은 지역 없음, 같은 교회의 다른 확정 건은 대구광역시 북구, 기존 people 2행. 원본 변경 없음.

## 변경 파일 및 위치
- `src/lib/region-stats.ts:27–29` — 대표의 유효 시/도·시군구가 있으면 유지, 없으면 같은 교회의 최초 유효 확정 주소 사용. 어떤 확정 주소도 유효하지 않을 때만 미분류. 지도·표·PDF·XLSX·CSV/TSV 공통 적용.
- `src/lib/region-church-list.ts:35–37` — 공통 요약 문구를 `사전신청 N교회 · 신청 인원 N명`으로 변경. 숫자 계산 변경 없음.
- `src/lib/region-stats.test.ts`, `src/lib/region-church-list.test.ts` — 대표 주소 없음/다른 확정 대구 주소, 전체 주소 없음, 미확정 주소 제외, 대표·2명·원본 불변·지도/목록 일치 회귀 검증. 기존 TSV 기대 문구 업데이트.
- `AGENTS.md`, `roadmap.md`, 지역 시각화 메모리 — 공통 주소 선택 규칙 및 완료 상태 반영.
- 서버 함수·권한·DB·people 인원 계산·회비·신청 건수·병합·대표 지정·과거 시즌 데이터 변경 없음. 기존 합계 계산·정렬·시즌명·생성일시 유지.

## 검증
- 관련 규칙 테스트 34개 통과, 자동 검사 기록 `build OK`.
- 시험 교회(실제 보고된 조건과 동일: 대표 주소 없음 + 다른 확정 건 대구 북구 + 기존 인원 2명)로 실제 내보내기 함수 실행.
- PDF 다운로드 후 첫 페이지 이미지 확인: 대구광역시 북구 / 테스트 / 홍길동 / 01012345678 / 2명 및 `사전신청 1교회 · 신청 인원 2명`, 시즌·생성일시 정상.
- XLSX 다운로드 내부 셀 확인: 같은 지역·교회명·요약·시즌 정상.
- 클립보드 TSV와 쉼표 CSV 직렬화 확인: 같은 지역과 요약, TSV 열 분리 유지.
- 시험 자료는 1교회/2명이며 실제 전체 교회·인원 합계라는 뜻이 아님.
- 공용 비밀번호 세션이 없어 로그인된 설정 조회→내보내기 전체 흐름은 미검증. 실제 Excel 프로그램 붙여넣기는 미검증. 게시하지 않음.
