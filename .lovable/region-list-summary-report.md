# 지역별 교회 목록 합계·복사 보정

## 변경 파일 및 위치
- `src/lib/region-church-list.ts`: `churchListSummary`/`churchListSummaryText` — 기존 확정 교회 단위 목록 행 수와 각 행의 기존 peopleCount만 합산하는 표시용 요약. `churchListDelimited` — 시즌/생성 일시, 합계, 열 머리글, 기존 교회 행 순서. `churchListCsv`는 쉼표 유지, `churchListClipboard`는 탭 구분. 특수문자 인용·수식 방어 유지.
- `src/lib/region-export.ts`: `exportRegionChurchList` — 복사에 TSV 사용; XLSX 1행 시즌·일시, 2행 합계, 3행 머리글(필터·고정행 위치도 이동); PDF 제목에 인원 합계 추가하고 표 시작 위치 조정. 집계표 PDF/PNG는 변경 없음.
- `src/lib/region-church-list.test.ts`: 기존 CSV 행 수 기대값 수정 및 기존 인원 합계/원본 불변/빈 목록/TSV 8열/특수문자·수식 방어 테스트 추가.
- `AGENTS.md`, `roadmap.md`, 지역 시각화 메모리: 표시 요약과 복사 형식 규칙 기록.

## 검증
- 32개 테스트 통과, 자동 타입 검사·빌드 `build OK`.
- 실제 내보내기 함수를 시험용 버튼에서 실행: PDF/XLSX 다운로드, TSV 클립보드 복사, 브라우저 예외 0.
- 시험 자료 교회 4곳 × 기존 인원 2명 → PDF·XLSX·복사 상단 `확정 교회 4곳 · 신청 인원 8명` 확인. 실제 자료가 4곳·8명이라는 주장은 아님.
- PDF 첫 페이지 이미지 확인: 제목·시즌·합계·일시·표 정상, 미분류 마지막.
- XLSX 읽기 확인: 합계 2행, 머리글 3행, 교회 4행, 연락처 문자열 선행 0 보존, 필터 A3:H3, 고정 A4, 계산 수식 없음.
- 클립보드 TSV 파싱 확인: 머리글/교회 각각 8열, 쉼표 포함 교회명 한 셀, CSV 문자열은 쉼표 유지. 실제 데스크톱 Excel에 붙여넣기 검증은 미실시.
- 서버 함수·DB·인원수 계산·회비·신청·병합·대표 지정·과거 시즌 데이터 변경 없음. 기존 목록과 지도/표 정합성 검사 유지.
- 로그인된 실제 설정 조회→내보내기 전체 흐름은 기존 공용 비밀번호 세션이 없어 미검증. 게시하지 않음.
